# بـرومـات (Promat) 🚀
**المكتبة الذكية لاستعراض، شرح، ترجمة، وتعديل برومبتات الذكاء الاصطناعي**

تطبيق مكتبي وأداة سطر أوامر تفاعلية مبنية بالكامل بلغة بايثون دون الحاجة لأي مكتبات خارجية (Pure Standard Python). يتيح البحث الذكي باللغتين العربية والإنجليزية في أكثر من 2,700 برومبت معتمد، مع شرح تحليلي دقيق لكل برومبت، ترجمة فورية، إمكانية التعديل والإضافة، وهندسة البرومات لتناسب أفضل النماذج (ChatGPT, Claude, Gemini, DeepSeek).

---

## ✨ المميزات الرئيسية

### 1. 🖥️ واجهة مستخدم مكتبية عصرية واحترافية
- تصميم أنيق بنمط Slate & Indigo ومريح للعين مع تقسيم مرن للشاشة (`PanedWindow`).
- **بحث فوري مباشر (Live Search)** مع ميزة التهدئة (Debounce) للتصفية السريعة أثناء الكتابة.
- اختصارات لوحة المفاتيح (`Ctrl+F` للبحث، `Ctrl+N` لإضافة برومبت، `Ctrl+C` للنسخ، `Delete` للحذف).
- تصنيفات ذكية مع عدادات حية (برمجة وتطوير، إنشاء صور، إنشاء فيديو، كتابة، تسويق، تعليم، أعمال، ترجمة، إلخ).

### 2. 💡 شرح تحليلي عالي الدقة لكل برومبت
- توليد توصيف دقيق ومباشر لموضوع ومهمة البرومبت الفعلي باللغة العربية (مثل: *برومبت لإنشاء فيديو لسيارة رياضية عند الغروب*، أو *برومبت لمطور بايثون لبرمجة أداة استخراج ويب*).
- تحليل تلقائي للشروط والقيود المفروضة على الذكاء الاصطناعي (مثل: كود فقط، محاكاة سطر أوامر، بدون شروحات، التفاعل خطوة بخطوة).
- تقديم نصائح عملية لأفضل صياغة لتوجيه النموذج.

### 3. 🌐 ترجمة فورية متزامنة للعربية
- ترجمة بضغطة زر واحدة في خيط خلفي غير معطل للواجهة عبر واجهة ترجمة مباشرة مدمجة دون تثبيت أي مكتبات.
- إمكانية التبديل بنقرة واحدة بين النص الأصلي الإنجليزي والترجمة العربية.

### 4. 🔍 محرك بحث عربي متقدم (Arabic NLP Normalization)
- معالجة ذكية للأخطاء الإملائية الشائعة وتوحيد الهمزات (`أ / إ / آ / ا`) والياء المقصورة والتاء المربوطة.
- إزالة علامات التشكيل والتنوين والشدة تلقائياً.
- تجريد سوابق اللغة العربية مثل أداة التعريف (الـ) وحروف العطف والجر المتصلة (مثل: البحث عن "المبرمج" يعطي نفس نتائج "مبرمج").

### 5. ✏️ التعديل الكامل والإضافة المباشرة (CRUD)
- محرر نصي تفاعلي يسمح بتعديل نصوص البرومات وحفظها فوراً محلياً.
- نافذة مخصصة لإضافة برومات جديدة وحفظها في المكتبة.
- دعم المفضلة (★) وحذف أو أرشفة البرومات غير المرغوبة.
- حفظ متزامن في خيط خلفي لمنع أي تعليق أو تجميد في الشاشة.

### 6. 🧩 دعم المتغيرات التفاعلية `${...}`
- اكتشاف ذكي لكافة المتغيرات المضمنة في البرومبت (مثل `${Position:Developer}`).
- تبويب تفاعلي لملء المتغيرات وتطبيقها بنقرة واحدة لتصبح جاهزة للنسخ والاستخدام.

### 7. ✨ التحسين الذكي وهندسة البرومبتات (AI Prompt Enhancer)
- إعادة صياغة البرومبت وفق أفضل ممارسات هندسة الأوامر (Prompt Engineering):
  - **ChatGPT / GPT-4o**: فصل رسائل System عن تعليمات User.
  - **Claude (Anthropic)**: استخدام أوسمة XML (`<role>`, `<context>`, `<rules>`, `<task>`).
  - **Gemini (Google)**: توجيهات التفكير المتسلسل والتنظيم المنطقي.
  - **DeepSeek**: أسلوب التفكير التحليلي والاستدلالي (Reasoning Directive).
- خيار لاختيار لغة القالب (عربي أو إنجليزي) مع إمكانية الحفظ كبرومبت جديد أو تصديره لملف نصي.

### 8. ⚡ أداة سطر الأوامر وتكامل OpenCode (`prompt_finder.py`)
- مطابقة سريعة لأي طلب من سطر الأوامر مع إمكانية إخراج النتائج بصيغة JSON (`--json`).
- تكامل تلقائي مع مساعدي وأدوات البرمجة الذكية.

## 🚀 طريقة التشغيل

### المتطلبات
- **نظام التشغيل:** Windows 10 / 11
- **بايثون:** Python 3.10+ مثبت على الجهاز.
- **الحزم:** **صفر تثبيت!** التطبيق يعتمد بالكامل على المكتبات القياسية المدمجة مع بايثون (`tkinter`, `urllib`, `json`, `re`, `threading`).

### التشغيل المباشر
- **عبر ملف التشغيل الصامت:**  
  انقر نقراً مزدوجاً على ملف [`برومات.bat`](file:///e:/برومات/برومات.bat).
- **أو عبر سطر الأوامر (Terminal / PowerShell):**
  ```powershell
  python prompt_desktop.py
  ```

### استخدام أداة سطر الأوامر
```powershell
python prompt_finder.py "أريد مبرمج بايثون لتطوير تطبيق ويب"
```
أو لاستخراج مصفوفة JSON:
```powershell
python prompt_finder.py --json "developer"
```
